# Orchestra AI brand identity

**Concept: The Intelligent Conductor.** Orchestra AI coordinates people, rules, document
intelligence and UiPath robots the way a conductor leads an orchestra. The identity is clean,
geometric and calm: blue-to-cyan light on deep navy or cool white.

The concept guides the design but is not a public tagline. Public copy uses exactly the same lines
as the product showcase end card. They are defined once, in `BRAND` in `brand-art.ts`:

| Line | Text | Where |
|---|---|---|
| Tagline | **Intelligent Workflow Orchestration Platform** | Under the logo on Login, page titles in link previews, and the social preview image |
| Short tagline | **Workflow orchestration** | Under the wordmark in the sidebar, where the full tagline does not fit |
| Slogan | **Orchestrate Intelligence. Empower Decisions.** | Headline of the social preview image, and the closing line of the showcase |

## Source of truth

All brand artwork is plain SVG markup generated by
[`apps/web/src/lib/brand-art.ts`](../apps/web/src/lib/brand-art.ts) (no JSX, no imports). It feeds:

| Consumer | File |
|---|---|
| React components (`OrchestraSymbol`, `Wordmark`, `OrchestraLogo`, `Orbi`, `BrandLoader`) | [`apps/web/src/components/brand.tsx`](../apps/web/src/components/brand.tsx) |
| Favicon (Next.js `icon` file convention) | `apps/web/src/app/icon.svg` |
| Apple touch icon, rendered to PNG at build time | [`apps/web/src/app/apple-icon.tsx`](../apps/web/src/app/apple-icon.tsx) |
| Web app manifest | [`apps/web/src/app/manifest.ts`](../apps/web/src/app/manifest.ts) |
| Static files for documents, slides and other tools | `apps/web/public/brand/*.svg` |

After changing the artwork, regenerate the static files (from `apps/web`):

```
pnpm brand:export
```

## Logo

The **orbital O**: a geometric ring in a blue-to-cyan gradient, an orbit that passes behind the
ring at the top and in front of it at the bottom, a node on the orbit and a small intelligence
star at the top right.

| File (`apps/web/public/brand/`) | Use |
|---|---|
| `orchestra-logo-light.svg` | Primary logo with wordmark, on light backgrounds |
| `orchestra-logo-dark.svg` | Primary logo with wordmark, on dark backgrounds |
| `orchestra-logo-mono.svg` | Single colour (`currentColor`), for print, stamps and watermarks |
| `orchestra-symbol.svg` | Standalone symbol (avatars, small spaces) |
| `orchestra-symbol-mono.svg` | Standalone symbol, single colour |
| `orchestra-app-icon.svg` | Symbol on a navy tile: favicon, app icon |

Rules:

- **Keep the proportions.** Scale the symbol and the lockup as a whole, and never stretch them.
- **Clear space** around the logo is at least half the symbol height.
- **Minimum size** is 16 px for the symbol on the navy app tile and 20 px on its own. Below 24 px,
  use the symbol without the wordmark.
- **Never rebuild the logo** from screenshots or the presentation board. Use these SVGs, or
  `OrchestraSymbol` / `OrchestraLogo` in the app.

The wordmark in the static lockups is live text in Sora 700, with fallbacks. Before using it in
print or design tools without Sora installed, convert it to outlines. In the app it is real HTML
text in the loaded Sora font.

## Colour

Brand tokens live in [`apps/web/src/app/globals.css`](../apps/web/src/app/globals.css) and do not
depend on the theme:

| Token | Value | Role |
|---|---|---|
| `--brand-blue` | `#2563EB` | Primary blue, start of the gradient |
| `--brand-sky` | `#0EA5E9` | Gradient midpoint |
| `--brand-cyan` | `#06B6D4` | Cyan accent, end of the gradient |
| `--brand-cyan-light` | `#22D3EE` | ORBI's eyes, highlights on dark |
| `--brand-navy` | `#0B1120` | Deep navy (app tile, dark canvas, ORBI's face) |
| `--brand-ink` | `#172033` | Wordmark on light backgrounds |
| `--brand-gradient` | `135deg, blue → sky → cyan` | `bg-brand-gradient`; `text-brand-gradient` for the "AI" |

Interface colours (surfaces, text, states) are theme tokens in the same file. Light and dark are
both first-class.

## Typography

| Role | Face | Where |
|---|---|---|
| Wordmark | **Sora 700** | `Wordmark`, `OrchestraLogo` |
| Major headings | **Sora 600** | Page titles (`PageHeader`), login headline, sign-in title, error and 404 titles: utility `font-display` |
| Interface | **Inter** | Everything else: forms, tables, data, body copy (`font-sans`, the default) |

Fonts are self-hosted by `next/font` in [`apps/web/src/app/layout.tsx`](../apps/web/src/app/layout.tsx).
Only Sora 600 and 700 are loaded; Inter is the variable font.

## ORBI, the mascot

**ORBI, Orchestra's Robotic Intelligence:** a friendly white robot with blue and cyan accents, a
deep navy digital face, expressive cyan eyes and the orbital O on its chest.

| Expression | File | Used for |
|---|---|---|
| `default` | `orbi-default.svg` | Generic empty states (no automation jobs, no audit events, no notifications) |
| `greeting` | `orbi-greeting.svg` | Login welcome, dashboard welcome |
| `thinking` | `orbi-thinking.svg` | Searches and filters with no results, 404 |
| `document` | `orbi-document.svg` | "No purchase requests yet", document intelligence at work |
| `approval` | `orbi-approval.svg` | "No decisions yet" in Approvals |
| `success` | `orbi-success.svg` | "You're all caught up" in Approvals |
| `error` | `orbi-error.svg` | Page-level errors (`ErrorState`), next to the real error message |

Rules:

- **ORBI sets the tone; it never carries information.** Statuses, counts and errors are always
  stated in text from real data, and ORBI appears beside that text, never instead of it.
- **Use ORBI sparingly**: empty states, onboarding, and moments that help (welcome, waiting for
  document intelligence, a page that failed to load). Keep it out of dense tables and charts.
- **ORBI is decorative by default** (`aria-hidden`). Pass `title` when ORBI is the only content.
- **Idle motion** (`<Orbi animated />`: a gentle float and blink) appears only on Login, the 404
  page and document processing, and `prefers-reduced-motion` turns it off.

## Favicon and browser metadata

- **`icon.svg`:** the symbol on a navy tile, legible in light and dark browser chrome.
- **`apple-icon`:** a 180 × 180 PNG generated from the same SVG.
- **Social preview (`opengraph-image`, `twitter-image`):** a 1200 × 630 PNG rendered at build time
  by [`apps/web/src/lib/og-card.tsx`](../apps/web/src/lib/og-card.tsx): the logo, the tagline, the
  slogan and ORBI greeting on navy. The fonts come from `@fontsource/sora` and `@fontsource/inter`, because
  the image renderer cannot read WOFF2. Absolute image URLs use `metadataBase`, which is the Vercel
  production domain, or `NEXT_PUBLIC_SITE_URL` when it is set.
- **`manifest.webmanifest`:** name "Orchestra AI", short name "Orchestra", start URL
  `/dashboard`, navy theme colour.
- **Metadata:** title template `%s · Orchestra AI`, application name, Open Graph site name and
  description, all taken from `BRAND` in `brand-art.ts`.
